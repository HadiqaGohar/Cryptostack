# TechNama - RACI Matrix

## Legend
- **R** = Responsible (does the work)
- **A** = Accountable (owns the outcome)
- **C** = Consulted (provides input)
- **I** = Informed (kept updated)

## Team Roles
- PM = Project Manager
- UX = UI/UX Designer
- WP = WordPress Developer
- BE = Backend Developer
- SEO = SEO Specialist
- SEC = Security Engineer
- ED = Editorial Team
- VID = Video Team
- QA = QA Engineer
