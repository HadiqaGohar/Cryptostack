# TechNama - Production Workflows

## 1. Editorial Workflow

### Article Creation Pipeline
```
Idea → Outline → Draft → Review → Edit → SEO Check → Publish → Promote
```

| Stage | Owner | Tools | SLA |
|-------|-------|-------|-----|
| Idea | Content Team | Editorial calendar | Weekly planning |
| Outline | Author | Google Docs | 1 day |
| Draft | Author | WordPress editor | 2-3 days |
| Review | Editor | WordPress comments | 1 day |
| Edit | Editor | WordPress editor | 1 day |
| SEO Check | SEO Specialist | Yoast SEO | 0.5 days |
| Publish | Editor | WordPress | Immediate |
| Promote | Content Team | Social media | Same day |

### Content Standards
- **Title:** 60 characters max, SEO-optimized
- **Excerpt:** 150-160 characters
- **Featured Image:** Required (400x250 minimum)
- **Categories:** 1-2 per post
- **Tags:** 3-5 per post
- **Word Count:** 800-2000 words
- **Readability:** Grade 8 level

## 2. Live Show Workflow

### Pre-Show (1-2 weeks before)
```
Guest Identification → Outreach → Confirm → Pre-Production → Promote
```

| Stage | Owner | Deliverable |
|-------|-------|-------------|
| Guest ID | Video Team | Guest shortlist |
| Outreach | Video Team | Invitation email |
| Confirm | Video Team | Signed agreement |
| Pre-Production | Video + Content | Topic, questions, thumbnail |
| Promote | Content Team | Social posts, newsletter |

### Show Day
```
Setup → Test → Go Live → Monitor → End Show
```

| Stage | Owner | Checklist |
|-------|-------|-----------|
| Setup | Video Team | OBS/streaming software |
| Test | Video Team | Audio, video, connectivity |
| Go Live | Video Team | Start stream |
| Monitor | Video Team | Chat, technical issues |
| End Show | Video Team | Save recording |

### Post-Show (1-3 days after)
```
Edit → Upload → Web Publish → Archive → Analyze
```

| Stage | Owner | Deliverable |
|-------|-------|-------------|
| Edit | Video Team | Final video file |
| Upload | Video Team | YouTube upload |
| Web Publish | WP Developer | Episode page live |
| Archive | Content Team | Show notes, tags |
| Analyze | SEO Specialist | Performance report |

## 3. Press Release Workflow

### Submission Pipeline
```
Submit → Review → Approve/Edit → Publish → Distribute
```

| Stage | Owner | Action |
|-------|-------|--------|
| Submit | External | Form submission |
| Review | Editor | Content review |
| Approve/Edit | Editor | Approval or revisions |
| Publish | Editor | WordPress publish |
| Distribute | Content Team | Social + newsletter |

### Review Criteria
- [ ] Newsworthy content
- [ ] Proper formatting
- [ ] No spam/promotional content
- [ ] Contact information valid
- [ ] Images/media included
- [ ] SEO optimization
